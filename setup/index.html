Mail setup

Settings for adding your mailbox to Outlook, iPhone, Android or any other mail app.

Your login

UsernameYour full email address, e.g. name@yourdomain.com
PasswordThe same password you use for webmail

Use the same username and password for both incoming and outgoing mail.

Server settings

ServerPortSecurity
Incoming (IMAP)mail.fleetmap.org993SSL/TLS
Outgoing (SMTP)mail.fleetmap.org587STARTTLS, password required
Outgoing (alternative)mail.fleetmap.org465SSL/TLS, password required

Do not use imap.yourdomain.com or smtp.yourdomain.com, even if your app suggests them. If sending fails on some networks (e.g. “sender address not valid”), use port 465 with SSL/TLS instead.

Outlook

  1. Add account, enter your email address, and choose IMAP.
  2. Turn on Show more and turn off “Use recommended settings”.
  3. Enter the incoming and outgoing servers from the table above.
  4. Enter your password and continue.

iPhone / iPad

If you were sent a profile link, open it in Safari, then install it from Settings → Profile Downloaded.

To set it up by hand:

  1. Settings → Apps → Mail → Mail Accounts → Add Account → Other → Add Mail Account.
  2. Choose IMAP and enter the servers from the table above.
  3. After saving, open the account → SMTP → mail.fleetmap.org and check that the username and password are filled in and Authentication is Password.

If sending fails with “not a valid address … rejected by the server”, the outgoing password is missing.

Android and other apps

Choose Other / IMAP / Manual setup and enter the settings above.
